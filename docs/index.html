关于2000年起的历史数据

本项目以2000年为监测时间轴起点，官方没有提供的时期不补零、不估算、不使用其他口径伪装；例如全国月度调查失业率2018年起公开发布，民间投资月度数据2012年起公开发布，全国统一住户调查收入序列2013年开始。

数据来源：国家统计局发布库、国家统计局公报。目前广州本地和部分结构性指标需完成官方历史公报映射后再入库。政策关联分析需另外建立可核验的政策事件索引。
