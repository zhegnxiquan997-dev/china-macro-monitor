# 中国经济长期指标监测（2000年至今）

网页：[中国经济历史看板](https://zhegnxiquan997-dev.github.io/china-macro-monitor/)

## 能做什么

- 2000年至今的长期观察时间轴，指标按官方实际可提供的年份入库，缺失不填0。
- 从统计指标列表选择不同指标，查看历史趋势、按年份或月份筛选、查看逐期表、下载CSV。
- 一条记录同时保留**统计期**、**官方实际发布日期**（有独立官方证据才填）、**抓取日期**、数据来源、统计口径。
- 发现官方修改既有数值时，保留版本，不覆盖旧值。
- 自动采集：GitHub Actions 每天北京时间10:30检查官方数据库；首次回填或重新核验可以手动运行。

## 数据准确性原则

1. **“统计期”和“发布日期”必须分开**。例如2026-08表示8月统计期，不代表8月发布。国家数据发布库通常不返回原始新闻稿发布日，因此历史官方发布日期显示“未核实”，绝不填成抓取当天。
2. **“当月”和“累计”分开**。社零当月同比与1—8月累计同比是两条不同序列。房地产、民间投资主要是累计统计。
3. **“名义”和“实际”分开**。年度居民可支配收入名义增速不是实际增速，实际增速必须另取官方数据。
4. **不拼接不可比序列**。全国统一居民收入从2013年开始，民间投资月报从2012年开始，全国城镇调查失业率2018年起按月公开发布。2011年住房价格统计口径调整。
5. **历史数据不能承诺每个指标都从2000年覆盖**。按每项指标的真实起点展示，部分字段需要官方公报补录。
6. **数据源追溯**。数值由国家统计局新版发布库查询或经核验的官方公报导入，第三方说明只用于研究接口位置，不视为指标数值来源。


## 经济研判模块（全国 vs 广州）

入口：[经济研判看板](https://zhegnxiquan997-dev.github.io/china-macro-monitor/analysis.html)，首页也可以点击“全国·广州对比与复苏信号”。

功能：
- 全国与广州同统计期比较：社零累计同比、餐饮收入累计同比、民间投资累计同比；只对齐两地都已入库的月份，不进行插值或伪造历史值。
- 复苏信号跟踪：全国社零20%、民间投资20%、房地产开发投资20%、工业利润15%、调查失业率15%、居民实际收入10%。同年精确3个月差比较（季度收入与上个季度比较），改善记80、平稳记50、走弱记20；缺失项不参与，展示有效权重，覆盖不足70%或可比项目少于4项则不显示总分。
- 指标改善阈值分别为0.3、0.5、0.5、1.0、0.2和0.3个百分点，调查失业率越低越好。**这是团队自定义规则，不是官方指数、经济预测或交易建议**。
- 广州快消解释：按同口径的已公布数据生成“证据—可能的经营含义—建议业务指标”。不从宏观数据直接推导经销商或门店销量。
- 缺失风险：广州民间投资和全国餐饮目前只有少量同步月份，这些比较只能显示当前数值，不会强行画出趋势。

技术：\`docs/analysis-core.js\` 为可单测的纯函数，\`docs/analysis.js\` 为交互绘图，\`tests/test_analysis.cjs\` 用 Node 内置测试框架验证同月对齐、评分覆盖率和缺失数据处理，\`.github/workflows/analysis-ci.yml\` 自动跑测试。

## 目录

- `indicators.json`：指标名称、类型、统计频率、起点及API映射。
- `archive_collector.py`：新版国家统计局接口采集与历史版本保存。
- `data/observations.json`：原始历史数值及版本的档案；长期保留。
- `data/official_import.csv`：需要人工核验的官方公报数据入口。
- `data/collector_state.json`：采集状态和上次运行时间。
- `docs/index.html`、`docs/app.js`、`docs/app.css`、`docs/data.json`：GitHub Pages网页。
- `.github/workflows/update.yml`：每日自动采集；手动运行时可以勾选“重新回填2000年以来历史”。
- `tests/test_collector.py`：统计期解析、来源约束、数据修订测试。

## 执行

登录 GitHub → **Actions** → **中国经济历史数据自动更新** → **Run workflow**。

默认按最近三年的月份检查新值与官方修订；若勾选 backfill，会重新检查历史可用年份。首次引入的新指标自动尝试完整历史回填。

如需手动增加真实官方数据，请在 `data/official_import.csv` 增加：

`indicator_id,period,value,source_url,source_title,published_at`

其中 `period` 可为 `YYYY-MM`、`YYYY-Q1` 至 `YYYY-Q4` 或 `YYYY`，`source_url` 必须是HTTPS政府官网。发布日期若未核实则留空。

## 运营限制

- 国家统计局2026年升级过数据接口；网站接口不是永不变更的官方API服务，可能出现地址变更、限流、HTML验证或缺失月份。
- 每次运行必须查看日志和数据覆盖情况；GitHub Actions运行成功只说明程序执行结束，并不保证所有指标有新数据。
- 工业企业利润、部分服务消费、广州本地细分指标及历史官方新闻稿发布日期，目前仍有待进一步完善官方接口/公报映射。
- 发布站点使用公开仓库，仅存放公开宏观数据，不要上传个人资料、公司未公开经营信息或密钥。
